# Browser Smoke Test in CI (Milestone 2, PR 4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Playwright test that drives the real app through setup, sign-in, upload, solve, export, the config page and sign-out, runnable locally with `make e2e` and in CI against the built Docker image, with a fake nova.astrometry.net so no test ever contacts nova.

**Architecture:** A dependency-free Node script (`frontend/e2e/fake-nova.mjs`) serves the recorded fixtures in `backend/tests/fixtures/nova/` at nova's URL shapes; the app runs unmodified with `NOVA_BASE_URL` pointed at it. One Playwright spec exercises the flow. Playwright's `webServer` starts the fake nova always and, locally, uvicorn on a scratch data directory serving the built frontend. In CI the existing `docker` job starts the image with the fake nova reachable on the host and runs the same spec. Closes #11.

**Tech Stack:** `@playwright/test` (new devDependency, owner-approved) with Chromium; Node 24 standard library for the fake nova; Pillow (already installed) to generate the fixture image once.

**Spec:** `docs/SPEC.md` § 12 (`ci.yml` on PR: lint, tests, docker build), CLAUDE.md (never call nova during tests; use the recorded fixtures; browser checks never touch `data/`), issue #11 (upload a fixture image with a fake solver, check the card reaches Solved and an export appears; motivation: the blank-page regression from a lost Vite proxy). Design agreed in chat 2026-09-10: fake nova rather than a code hook; CI tests the built image; local runs use uvicorn from source.

## Global Constraints

- No test may contact nova.astrometry.net. The fake nova replays `backend/tests/fixtures/nova/` and nothing else.
- Nothing touches the checkout's `data/` directory: local runs use a temp data dir created by the Playwright config and removed afterwards; CI uses the image's anonymous `/data` volume.
- The only new npm dependency is `@playwright/test`. The fake nova uses Node's standard library only. No new Python dependency.
- The app is not modified for the test. `NOVA_BASE_URL` and `NOVA_API_KEY` are the existing configuration knobs.
- The fixture image is 3000 × 2250 pixels so the recorded annotation coordinates (from a 3000 × 2250 solve copy) land inside it, and is committed once (about 150 KB) rather than generated per run.
- Frontend conventions: TypeScript strict for the spec and config; `npm run lint` (eslint + `tsc --noEmit -p tsconfig.json`) stays clean; vitest's include stays `src/**/*.test.ts` so it never picks up the spec.
- CI budget: the browser step adds at most about two minutes to the docker job.
- Run `make lint test` before every commit that touches code. Conventional commit messages ending with:

**Interfaces:**

- Produces: an HTTP server on `FAKE_NOVA_HOST` (default `127.0.0.1`) : `FAKE_NOVA_PORT` (default `8901`) whose responses make `NovaSolver` complete a solve in two polls: `POST /api/login` → `login.json`; `POST /api/upload` → `upload.json` (subid 16030035); `GET /api/submissions/16030035` → `submission_pending.json` on the first call after an upload, then `submission_ready.json` (job 16837720); `GET /api/jobs/16837720` → `job_solving.json` first, then `job_success.json`; `GET /api/jobs/16837720/annotations/` → `annotations.json`; `GET /api/jobs/16837720/info/` → `job_info.json`; `GET /wcs_file/16837720` → `wcs.fits` as `application/octet-stream`; `GET /status/<id>` and `GET /joblog/<id>` → a one-line HTML page (the UI links there); `GET /` → `{"ok": true}` for readiness; anything else → 404 JSON. Any id is accepted for the two poll endpoints so a second upload in the same run works. Every request is logged as one line to stdout.

- [ ] **Step 1: Write the fixture generator** — `backend/scripts/make_e2e_fixture.py`

```python
"""Write frontend/e2e/fixtures/field.jpg: a 3000 × 2250 dark frame with deterministic stars.

The recorded nova fixtures come from a 3000 × 2250 solve copy, so this size puts every
recorded annotation inside the image. Run with ``make e2e-fixture``.
"""

from __future__ import annotations

import random
from pathlib import Path

from PIL import Image, ImageDraw

REPO_ROOT = Path(__file__).resolve().parent.parent.parent
TARGET = REPO_ROOT / "frontend" / "e2e" / "fixtures" / "field.jpg"
WIDTH, HEIGHT = 3000, 2250


def main() -> None:
    img = Image.new("RGB", (WIDTH, HEIGHT), (8, 10, 20))
    draw = ImageDraw.Draw(img)
    rng = random.Random(7)
    for _ in range(400):
        x, y = rng.uniform(0, WIDTH), rng.uniform(0, HEIGHT)
        r = rng.uniform(1, 4)
        draw.ellipse([x - r, y - r, x + r, y + r], fill=(230, 230, 255))
    TARGET.parent.mkdir(parents=True, exist_ok=True)
    img.save(TARGET, "JPEG", quality=70, optimize=True)
    print(f"wrote {TARGET} ({TARGET.stat().st_size // 1024} KB)")


if __name__ == "__main__":
    main()
```

- [ ] **Step 2: Write the fake nova** — `frontend/e2e/fake-nova.mjs`

```js
// A fake nova.astrometry.net that replays the recorded fixtures, so the browser smoke test
// never contacts nova (CLAUDE.md). Standard library only; started by Playwright's webServer.
//
//   FAKE_NOVA_PORT   default 8901
//   FAKE_NOVA_HOST   default 127.0.0.1 (0.0.0.0 in CI so a container can reach it)
//   NOVA_FIXTURES    default ../backend/tests/fixtures/nova relative to this file
import { createServer } from 'node:http'
import { readFileSync } from 'node:fs'
import { dirname, join } from 'node:path'
import { fileURLToPath } from 'node:url'

const here = dirname(fileURLToPath(import.meta.url))
const fixtures = process.env.NOVA_FIXTURES ?? join(here, '..', '..', 'backend', 'tests', 'fixtures', 'nova')
const port = Number(process.env.FAKE_NOVA_PORT ?? 8901)
const host = process.env.FAKE_NOVA_HOST ?? '127.0.0.1'

const fixture = (name) => readFileSync(join(fixtures, name))
const json = (name) => ({ type: 'application/json', body: fixture(name) })

// How many times each poll endpoint has been asked since the last upload: the first answer
// is "not yet", every later one is "done", which is the shortest path through the worker.
let submissionPolls = 0
let jobPolls = 0

function route(method, path) {
  if (method === 'GET' && path === '/') return { type: 'application/json', body: '{"ok": true}' }
  if (method === 'POST' && path === '/api/login') return json('login.json')
  if (method === 'POST' && path === '/api/upload') {
    submissionPolls = 0
    jobPolls = 0
    return json('upload.json')
  }
  if (method === 'GET' && /^\/api\/submissions\/\d+$/.test(path)) {
    return json(submissionPolls++ === 0 ? 'submission_pending.json' : 'submission_ready.json')
  }
  if (method === 'GET' && /^\/api\/jobs\/\d+\/annotations\/$/.test(path)) return json('annotations.json')
  if (method === 'GET' && /^\/api\/jobs\/\d+\/info\/$/.test(path)) return json('job_info.json')
  if (method === 'GET' && /^\/api\/jobs\/\d+$/.test(path)) {
    return json(jobPolls++ === 0 ? 'job_solving.json' : 'job_success.json')
  }
  if (method === 'GET' && /^\/wcs_file\/\d+$/.test(path)) {
    return { type: 'application/octet-stream', body: fixture('wcs.fits') }
  }
  if (method === 'GET' && /^\/(status|joblog)\/\d+$/.test(path)) {
    return { type: 'text/html', body: '<html><body>fake nova</body></html>' }
  }
  return null
}

const server = createServer((req, res) => {
  const url = new URL(req.url ?? '/', 'http://fake-nova')
  // Drain the request body (uploads are multipart) before answering.
  req.on('data', () => undefined)
  req.on('end', () => {
    const hit = route(req.method ?? 'GET', url.pathname)
    console.log(`${req.method} ${url.pathname} -> ${hit ? 200 : 404}`)
    if (!hit) {
      res.writeHead(404, { 'content-type': 'application/json' })
      res.end('{"status": "error", "errormessage": "not in the fixtures"}')
      return
    }
    res.writeHead(200, { 'content-type': hit.type })
    res.end(hit.body)
  })
})

server.listen(port, host, () => console.log(`fake nova listening on http://${host}:${port} (fixtures: ${fixtures})`))
```

`frontend/e2e/global-teardown.ts`:

```ts
import { rmSync } from 'node:fs'

/** Remove the scratch data dir the config created (never one the caller supplied). */
export default function globalTeardown(): void {
  const created = process.env.E2E_DATA_DIR_CREATED
  if (created) rmSync(created, { recursive: true, force: true })
}
```

Note on types: the config imports Node modules; `tsc --noEmit -p tsconfig.json` only includes `src` and `vite.config.ts`, and Playwright transpiles its own config, so no `@types/node` is needed. eslint lints `e2e/*.ts` and `playwright.config.ts` under the TypeScript config without type information; `process` is fine there (typescript-eslint disables `no-undef` for TS files). import { expect, test } from '@playwright/test'

const PASSWORD = 'e2e-password-1'

// One story, in order: a fresh install is set up, an image is solved and exported, the

test('first run: setup, sign in, solve, export, config, sign out', async ({ page }) => {

  await page.getByLabel('Password (at least 8 characters)').fill(PASSWORD)
  await page.getByLabel('Password again').fill(PASSWORD)
  await page.getByLabel('Site title (optional)').fill('E2E sky')
  await page.getByRole('button', { name: 'Finish setup' }).click()
  await expect(page).toHaveURL(/\/login$/)

  await page.getByLabel('Password').fill(PASSWORD)
  await page.getByRole('button', { name: 'Sign in' }).click()
  await expect(page).toHaveURL(/\/$/)
  await expect(page.getByRole('heading', { level: 1 })).toHaveText('E2E sky')

  await page.locator('input[type=file]').setInputFiles(FIXTURE)
  await page.getByPlaceholder('Title (optional)').fill('Orion')
  await page.getByRole('button', { name: 'Upload & solve' }).click()
  const card = page.locator('article.card', { hasText: 'Orion' })
  await expect(card.locator('.badge')).toHaveText('Solved', { timeout: 60_000 })
  await expect(card.getByText(/\d+ objects/)).toBeVisible()

  await card.getByRole('button', { name: 'Export' }).click()
  await expect(card.locator('img[alt="Orion annotated"]')).toBeVisible({ timeout: 60_000 })
  await expect(card.getByRole('link', { name: 'Download full-resolution export' })).toBeVisible()

  await page.getByRole('link', { name: 'Config' }).click()
  await expect(page).toHaveURL(/\/config$/)
  await page.getByLabel('Site title').fill('Renamed sky')
  await page.getByRole('button', { name: 'Save changes' }).click()
  await expect(page.getByText('Saved.')).toBeVisible()
  await expect(page.getByRole('heading', { level: 1 })).toHaveText('Renamed sky')

  await page.getByRole('button', { name: 'Log out' }).click()
  await expect(page).toHaveURL(/\/login$/)
  await page.goto('/')
  await expect(page).toHaveURL(/\/login$/)
  await page.goto('/setup')
  await expect(page.getByText('This site is already set up.')).toBeVisible()
